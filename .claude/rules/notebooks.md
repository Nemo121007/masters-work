# Блокноты

Перед правкой или ревью прочитать целиком: `notebooks/AGENTS.md`; для markdown-ячеек — `report/manuals/style.md`
и `report/manuals/glossary.md`. Контекст текущей ревизии — `report/manuals/notebook_review.md`, решения — «Принятые решения»
в `report/manuals/rewrite_plan.md`.

- Большие блокноты целиком не читать: `grep -n`, затем `sed -n` по номерам строк.
- После правки — `python -m json.tool <файл> > /dev/null`.
- Рабочая копия блокнота пользователя (выводы, путь к данным, `SHOW_PLOTS`) сохраняется: в коммит — только
  правки задачи.
- Изменение кода модели — обновить её markdown; блокнот целиком запускает пользователь.
- Варианты `*_anon.ipynb` (анонимизированные данные) повторяют код основных блокнотов: правка модели вносится
  в оба варианта.
