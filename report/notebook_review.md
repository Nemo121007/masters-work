## Цель

Методологически корректное сравнение **разных** моделей обнаружения аномалий. Решения не должны сводить одну
модель к другой; общие для моделей правила (время, точки без оценки, замена отвергнутых точек, подбор порога)
применяются единообразно.

## Порядок работы по модели

1. Разбор проблем модели: список проблем со следствиями, варианты решения, рекомендация.
2. Обсуждение по одному вопросу; каждое решение сразу записывается в «Принятые решения» (с датой; следствия
   помечаются как следствия).
3. Текст markdown-ячейки модели по `report/style.md` → запись в блокнот → проверка в IDE → одобрение.
4. Код по одобренному тексту.
5. Тесты: синтетика с известным ответом (новый `notebooks/checks/verify_<модель>.py`) и ячейка модели
   на `data/test.csv`. Тесты не прошли — остановиться, выяснить причину, спросить с вариантами решения.
   Прошли — описание модели в `report/Отчёт.tex` по md-ячейке (исходник — ячейка) и коммит.
6. Коммит: сообщение на русском, по строке на файл («файл: что сделано»), затем очистка `change.log`.

## Правила

- Правка кода блокнота и `app/` — отдельным решением; правка отчёта — после подтверждения;
  `docs/notes/methods.md` — только после явного подтверждения (по AR, ARIMA, фильтру Калмана ещё не обновлён).
- Выводы блокнота, таблицы и разбор результатов в отчёте — только после прогона на реальных данных
  (на `data/test.csv` — синтетика, выводы о моделях не делаются).
- Полный прогон блокнота — только с разрешения; частичный прогон нужных ячеек для проверки — допустим.
- Тексты: безличный стиль, без «пользователь», «агент», личных местоимений; лаконично; формулы вместо слов;
  термины по глоссарию; формулировка «отдельным решением», не «по команде».
- Ответы: коротко и точно; вопросы — с вариантами и рекомендацией.

## Техника правки блокнота

- Блокнот большой: искать строки `grep -n`, смотреть `sed -n`, заменять диапазоны строк `sed -i` по номерам,
  после каждой правки — `python -m json.tool notebooks/example_model.ipynb > /dev/null`.
- Новый текст ячейки — во временный файл, строки JSON — через `json.dumps(..., ensure_ascii=False)`;
  последняя строка ячейки — без `\n` и без запятой.
- Осторожно: `sed -i "${n}r file"` с пустым `n` вставляет файл после каждой строки (случай 2026-10-30).
- Новый код — по `black` (`line-length = 120`): проверка выгрузкой ячейки во временный `.py` и `black --check`.

## Общий каркас в блокноте (реализован)

- Общие константы: `GRID_STEP_SEC` (10 с), `TIME_GAP_SEC` (180 с), `THRESHOLD_LOG_POINTS` (60).
- Точки без оценки: оценка аномальности `NaN`, маска `scored`; `evaluate_test(frame, predicted, scored)`,
  `trajectory_series_pair(..., scored)`; `app/evaluation` — метка `NaN`, покрытие (3 столбца).
- Порог: `threshold_candidates` (180 квантилей + 60 значений в логарифмической шкале) для всех моделей;
  `select_threshold_from_records`; `_threshold_record(..., scored)`.
- Модели с заменой отвергнутых точек — общий шаблон: `<модель>_detect(frame, params, taus)` считает сразу
  все кандидаты порога → `(scores (C, N), rejected (C, N))`; `select_<модель>_threshold`: прогон без замены
  (`tau = inf`) → `threshold_candidates` (+ $\chi^2_{0.999}(2)$ для NIS) → пакетный прогон → записи → выбор.
- `time_segments(frame, mask)` — отрезки по разрывам по времени, из точек с одинаковым временем — первая.
- Модели прогноза AR/ARIMA: `fit_forecast_detector`, `forecast_detect`, `select_forecast_threshold`,
  `forecast_predict`.

Найденные ловушки:

- statsmodels вблизи единичного корня: стационарное начальное состояние даёт правдоподобие 0
  или `LinAlgError` → условное правдоподобие (приближённо диффузное начало, `loglikelihood_burn`),
  оптимизация из двух стартов.
- Оценка $\sigma$ фильтра Калмана уходит к нулю при численном вырождении правдоподобия → нижние границы.
- Квантильная сетка порога не даёт кандидатов в провале двугорбого распределения → логарифмическая шкала.
- Апостериорные величины GP в GP-EKF (среднее, дисперсия, якобиан) табулируются на сетке скоростей и
  интерполируются билинейно: точный расчёт на каждом шаге фильтра при 240 кандидатах порога и 1000 опорных
  точках невыполним по времени. Шаг сетки — ℓ_min/4, запас 4ℓ_max, не больше 301 узла на ось. В markdown
  не описано — вопрос открыт.

## GP-EKF: реализация и что разобрать

Решения — `report/rewrite_plan.md`, «GP-EKF, 2026-10-30». Ячейка `gp-ekf-code-cell`: `fit_kalman_on_train` →
`gp_ekf_smoothed_transitions` (KalmanSmoother statsmodels, отрезки штатного хода) → `fit_gp_ekf_correction`
(GP на ось, ARD, маргинальное правдоподобие, L-BFGS-B, до 1000 опорных точек, `SEED`; сетка скоростей) →
`fit_gp_ekf_noise` (σ_acc по осям и σ_meas по условному правдоподобию собственного цикла EKF, градиент
конечными разностями за один проход) → `select_gp_ekf_threshold` / `gp_ekf_detect` (ядро `_gp_ekf_filter`,
по образцу `kalman_detect`). Контроль — `gp_ekf_explained_share`. Импорт `KalmanSmoother` добавлен в ячейку
импортов. Используются `fit_kalman_on_train`, `kalman_process_noise`, `KALMAN_*` из ячейки фильтра Калмана.

Результаты `verify_gp_ekf.py` (2026-10-30):

- Проходят: нулевая поправка → NIS фильтра Калмана (5.8e-08); сетка = точный GP (1.6e-02 σ_f); якобиан
  аналитический = численный; сетка ≈ точный якобиан (2.6e-02); наклон среднего GP к истинному полю 0.982
  (занижения сглаживателем нет); медиана NIS 1.20; точки без оценки, совпадающее время, разрыв, выброс
  с заменой и без, перезапуск. Поле и 40 эпизодов аномалий: GP-EKF и фильтр Калмана — TP 169, FP 0, FN 0.
- Не проходят:
  1. Доля дисперсии ускорения, объяснённая средним GP: обучающая синтетика 0.722, тестовая (другой seed)
     0.184 при пороге 0.3. Гипотеза: на тестовой траектории другие скорости (поворот смещает область) —
     проверить покрытие скоростей; возможно, тест задан неудачно.
  2. σ_acc = (0.0157, 0.018) м/с² при истинном 0.01 (σ_meas 5.99 при 6.0 — точно). Гипотеза: модель
     кусочно-постоянного ускорения на шагах до 170 с не описывает поле, меняющееся внутри шага, —
     ошибка модели уходит в шум ускорения; проверить на синтетике без длинных шагов.
- `data/test.csv`: ℓ 0.06–0.3 м/с (GP подгоняется под шум), сетка упирается в 301 узел, доля на тестовой
  выборке −0.183 и −0.092 (поправка не переносится); σ_acc ≈ 0.004–0.006 м/с², σ_meas ≈ 4.8 м; F1 0.806
  и 0.925; время ~150 с на сценарий. Выводы о моделях по `test.csv` не делаются (синтетика).
- Диагностика (2026-10-30, скрипт в scratchpad, код не менялся):
  1. Перенос поправки — неудачный тест, не дефект модели: на тестовой синтетике скорости 1.4–8.4 м/с против
     4.3–34 м/с на обучающей, поле слабее шума; доля, объяснённая истинным полем (потолок), 0.187, средним GP —
     0.184; R² среднего GP к истинному полю 0.970. Проверку заменить: R² к истинному полю и доля относительно потолка.
  2. σ_acc: при шаге 10 с без длинных шагов — (0.0117, 0.0129) при 0.01, с длинными шагами — (0.016, 0.018);

## Фильтр Хэмпела: разбор (2026-10-30, выбрана постановка A)

Сейчас: модуль скорости $v_i$ от предыдущей точки ($v_0=0$, Δt=0 → 1 с); центрированное окно 21 точка
(h=10), края — дополнение крайним значением; $s_i=|v_i-m_i|/(1.4826\,\mathrm{MAD}_i+10^{-9})$; обучения нет,
порог — квантили и 3, 3.5, 5; $h$ задан вручную; без точек без оценки и без замены.

Проблемы:

1. Одиночный выброс даёт два всплеска скорости («туда» на $i$, «обратно» на $i+1$) → ложное срабатывание
   на штатной точке $i+1$.
2. Окно в точках пересекает разрывы по времени; скорость через разрыв — средняя за разрыв.
3. Края ряда — дополнение крайним значением → искусственная оценка (должны быть точки без оценки).
4. Совпадающее время: Δt=0 → 1 с → огромная скорость у дубликата (общее правило: первая точка, остальные
   без оценки).
5. $v_0=0$ у первой точки и первой точки после разрыва — должны быть без оценки.
6. MAD=0 (стоянка, квантование) при ε=10⁻⁹ → $s_i\sim10^9$ при малом отклонении; нужна нижняя граница
   масштаба.
7. Длинный эпизод аномалии: медиана устойчива, пока аномальных точек в окне ≤ h; при смещённом эпизоде
   скорость аномальна только на входе и выходе — свойство метода, описать.
8. Не причинная: окно включает h будущих точек (~100 с); задержка обнаружения несравнима с причинными
   моделями (уже в плане, 3.x).
9. $h$ вручную, кандидаты порога 3/3.5/5 вместо общей сетки — неравный объём подбора.

Варианты постановки:

- **A (рекомендован):** пакетный Хэмпел по скорости с общими правилами — центрированное окно в пределах
  отрезка между разрывами по времени; точки без оценки (первая точка отрезка, дубликаты времени, края
  с неполным окном); нижняя граница масштаба MAD по штатному ходу обучающей выборки; замена отвергнутых точек
  вторым проходом (скорость пересчитывается без отвергнутых точек, след на $i+1$ исчезает); общая сетка порога.
- **B:** причинный Хэмпел (хвостовое окно, скорость от последней принятой точки) — без задержки, но близок
  к MPCT (скорость от якоря и порог); противоречит цели сравнения разных моделей.
- **C:** Хэмпел по составляющим скорости $(v^o,v^n)$ вместо модуля — ловит смену курса; дополнение к A.

Вопрос: A, B или A + C. После выбора — детали A по одному: окно в точках или секундах, размер окна и его
подбор, нижняя граница MAD, порог 3 в сетке кандидатов, второй проход замены (по кандидатам порога).

## DBSCAN: разбор (2026-10-30, выбрана постановка A)

Сейчас: признаки точки $(\Delta o_i,\Delta n_i,v_i,a^{\mathrm{acc}}_i,\Delta\psi_i,\log\max(\text{индекс формы},1))$, робастная
нормировка по штатному ходу обучающей выборки; DBSCAN (min_samples 8) по всей обучающей выборке, ε — 5 квантилей
8-расстояния, выбор по MCC и операционной ошибке длины; на тестовой выборке кластеризация заново по тестовому облаку;
аномалия — шум DBSCAN; индекс формы — 6 точек.

Проблемы:

1. Кластеризация заново на тестовой выборке (план, 1.4): разметка зависит от состава теста (доля аномалий 28–31%
   против 61–70%, другой объём → при том же ε другая плотность); модель не переносится, решение использует весь тест.
2. $\Delta o_i$, $\Delta n_i$ — направление движения и не делятся на $\Delta t$: курсы обучающей выборки привязаны
   к маршрутам (районы и маршруты выборок разные) → новый курс на тесте — шум; шаг после паузы — шум.
3. На обучающей выборке DBSCAN по всем точкам: при 61–70% аномалий длинные эпизоды с согласованными признаками
   образуют свои кластеры и не размечаются.
4. Точки без оценки отсутствуют: первая точка (скорость 0, ложный всплеск ускорения у второй — п. 4 плана),
   признаки через разрыв по времени, дубликаты времени (Δt → 1 с), индекс формы у первых 6 точек = 1.
5. Выброс портит признаки следующей точки (скорость и курс «обратно») — как у Хэмпела.
6. Δψ на малой скорости (стоянка) — шум курса; индекс формы — окно в точках через паузы.
7. Подбор: 5 значений ε, min_samples фиксирован (план, 3.1 — неравный объём подбора).

Варианты постановки:

- A (рекомендован): DBSCAN обучается на штатном ходу обучающей выборки → набор опорных (core) точек; точка любой
  выборки — аномалия, если до ближайшей опорной точки дальше ε (правило отнесения DBSCAN к кластеру). Модель
  переносится на тест без перекластеризации, решение по точке не зависит от остальных точек теста (причинно при
  причинных признаках). ε — по разметке обучающей выборки, как сейчас.
- B: оставить перекластеризацию теста (пакетная, трансдуктивная модель), исправить только признаки.
- C: DBSCAN по всей обучающей выборке с переносом опорных точек — аномальные кластеры становятся «нормой».

Признаки (после выбора постановки): убрать $\Delta o$, $\Delta n$; скорость, ускорение, скорость поворота
(Δψ/Δt) и индекс формы — по последней принятой точке (второй проход), точки без оценки по общим правилам.

## DONUT: разбор (2026-10-30, выбрана постановка A)

Сейчас: окна 16 точек относительных координат (км), нормировка по окнам, обрезка ±8 при обучении и ±30 при

Проблемы: (1) план, 1.2 — в генеративной модели Pyro априорное распределение $z$ — сам энкодер $q(z|x)$, KL в ELBO

точки вне окон — 0, максимум по окнам (выброс делает аномальными до ±15 соседей); (6) след выброса;
(7) 10 эпох без контроля, σ = 1 вручную.

Варианты: A (рекомендован) — DONUT по статье с общими правилами: признаки $(v,a^{\mathrm{long}},a^{\mathrm{lat}})$;

её признаков (последняя точка окна, по выборке $z$); калибровка, ранняя остановка, seed — как у LSTM; точки без
оценки — первые 17 точек отрезка; второй проход; общая сетка порога. Отличие от LSTM и TCN — вероятностная

## HMM: разбор (2026-10-30, выбрана постановка A)

Сейчас: наблюдения $(v, a^{\mathrm{acc}}, \Delta\psi)$ по `trajectory_kinematics`, робастная нормировка по штатному ходу;
три отдельные гауссовские HMM — $\theta_N$ (3 состояния) по отрезкам штатного хода, $\theta_A$ (3) по отрезкам
аномалий, $\theta_F$ (2) по «быстрым» аномалиям ($v\ge8$ м/с); по 6 самых длинных отрезков класса длиной 30–1200
точек, шаг ≤ 90 с; EM 8 итераций; оценка — $\max_k\ell_i(\theta_k)-\ell_i(\theta_N)$, $\ell_i$ — причинное
предсказательное правдоподобие по всему ряду; порог — квантили. Единственная модель, обученная на обоих классах.

Проблемы: (1) три независимые модели — переходы между штатным ходом и аномалией не моделируются, хотя эпизоды
длинные (в test.csv в среднем ~69 точек): устойчивость эпизода — главное, что HMM может выучить; (2) обучение
на 6 отрезках класса, обрезанных до 1200 точек, — произвольная подвыборка; (3) EM 8 итераций без сходимости, одна
инициализация; (4) модель «быстрых» аномалий с порогом 8 м/с — ручная подстройка под данные; (5) признаки —
Δt = 0 → 1 с, первая точка, через разрывы, Δψ на стоянке; (6) фильтр проходит через разрывы по времени без
перезапуска, нет точек без оценки; порог разрыва 90 с; (7) след выброса на следующей точке; (8) свои квантили
вместо общей сетки.

Варианты: A (рекомендован) — одна HMM с переключением: состояния штатного хода ($K_N$) и аномалии ($K_A$) в одной
цепи; эмиссии и переходы (в том числе между классами) — EM на всех отрезках обучающей выборки с ограничением:
в размеченной точке допустимы только состояния её класса; оценка — причинная апостериорная вероятность класса
аномалии $P(S_i\in A\mid o_{1:i})$; признаки $(v,a^{\mathrm{long}},a^{\mathrm{lat}})$, перезапуск фильтра в начале
отрезка, точки без оценки, второй проход, общая сетка порога плюс 0.5. Отличие от остальных — моделирует
длительность эпизодов и использует разметку при обучении. B — две модели классов (штатный ход, аномалия)
с отношением правдоподобий, без «быстрой» модели; исправить 2, 3, 5–8.

## MPCT: разбор (2026-10-30, выбрана постановка A)

Статья (Custers et al., по docs/notes/methods.md): самая длинная подпоследовательность точек, в которой скорость
между соседними выбранными точками не выше $v_+$ (глобальный оптимум); аномалии — остальные точки.

Сейчас: жадный якорь — последняя принятая точка; точка отвергается при скорости от якоря $>v_+$ или индексе формы
(путь/смещение за 6 точек) $>\tau_{\mathrm{shape}}$; сетка 5 × 3 значений, MCC; расстояние — ENU (в markdown —
геодезическое); оценка — только у отвергнутых точек, у принятых 0.

Проблемы: (1) жадный якорь — ловушка: если якорем стала аномальная точка (первая точка ряда без проверки или
принятая после серии), следующие штатные точки отвергаются, пока скорость от якоря не упадёт ниже $v_+$; статья
решает это глобальным оптимумом; (2) нет перезапуска после разрыва по времени: скорость от якоря через паузу мала,
выброс после паузы принимается; (3) индекс формы — по всем точкам, включая отвергнутые: выброс даёт след на 6
следующих точках; на стоянке (смещение ≈ 0) индекс формы огромен — ложные срабатывания; индекса формы нет в статье;
(4) ENU вместо геодезического расстояния (план, 4); (5) $\Delta t$ ≥ 1 с вместо правила совпадающего времени; нет
точек без оценки; (6) сетка 15 пар (план, 3.1).

Варианты: A (рекомендован) — MPCT по статье: в каждом отрезке между разрывами по времени — самая длинная
подпоследовательность со скоростью между соседними выбранными точками $\le v_+$ (динамическое программирование,
предшественник ищется среди точек за последние 180 с — иначе $O(n^2)$); аномалии — точки вне неё; без индекса
формы; $v_+$ — единственный параметр, частая сетка (30 значений) по MCC; пакетная модель (как Хэмпел). B —
сохранить причинный жадный якорь, исправить 2–6, инициализацию якоря в начале отрезка и индекс формы по принятым
точкам.
