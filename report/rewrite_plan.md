### Принятые решения

Цель эксперимента — сравнение разных моделей; решения не должны сводить одну модель к другой.

Общее:

- Точка без оценки (2026-10-29). Если модель не может дать оценку аномальности в точке (первые точки ряда,
  окрестности разрывов по времени, точки вне допустимых окон и т. п.), точка получает состояние «без оценки».
  - Код: оценка аномальности — `float64` с `NaN` и булева маска `scored`; в метке предсказания
    `TrajectorySeries` — `NaN` (0 — аномалия, 1 — штатный ход). `select_anomaly_threshold` не заменяет `NaN` на 0.
  - Траектория: точка без оценки восстанавливается линейной интерполяцией по времени между соседними
    принятыми точками, как отвергнутая (заказчик не доверяет непроверенной точке и восстанавливает её по
    соседям). В маске состояние «без оценки» хранится отдельно от классов.
  - Точность, полнота, F1, MCC — только по точкам с оценкой, у каждой модели своё подмножество.
  - Подбор порога: MCC — по точкам с оценкой; в операционной ошибке длины точки без оценки исключаются из
    ломаной, как отвергнутые.
  - Отклонение $d_i$, RMSE, максимальное отклонение, DL — по заполненной траектории с интерполяцией точек
    без оценки.
  - Покрытие в итоговых таблицах: доля точек без оценки от всех точек тестовой выборки; доля эталонных
    аномальных точек среди точек без оценки (остальное — штатный ход); доля эталонных аномальных точек
    без оценки от всех аномальных.
  - Задержка обнаружения — от начала эпизода аномалии; точки без оценки в начале эпизода входят в задержку.
    Следствие: эпизод без единой точки с оценкой — пропуск со штрафом, равным длине эпизода.
  - Допускается правка `app/evaluation/` под третье состояние метки и столбцы покрытия.
  - Термины «точка без оценки» и «покрытие» внесены в глоссарий.

AR и ARIMA:

- `dynamic=True` в `get_prediction` — ошибка (подтверждено 2026-10-29); исправление ещё не назначено.
- AR остаётся моделью уровня $o_i$, $n_i$ (2026-10-29): перевод на приращения сделал бы её частным случаем
  ARIMA, а цель — сравнение разных моделей.
- Две независимые AR(2) — по $o_j$ и по $n_j$, у каждой оси свои параметры (2026-10-30); решение общее:
  оценка аномальности, замена в лагах и перезапуск прогноза — сразу по обеим осям. При прогоне выводятся
  $\phi_1$, $\phi_2$, $\sigma$ по каждой оси; при заметном расхождении — рассмотреть общие $\phi$, $\sigma$
  с отдельной константой $\mu$ на ось. Вопросы по AR закрыты.
- Порог разрыва по времени для AR — 180 с, как в глоссарии, через общую константу (2026-10-30).
- Время в AR (2026-10-30): регулярная сетка по времени с шагом 10 с; точка относится к ближайшему узлу
  (округление); из точек, попавших в один узел, остаётся первая, остальные — точки без оценки.
  - Внутри отрезка (интервалы до 180 с) пустые узлы — пропуски (`NaN`); фильтр statsmodels в них делает
    прогноз без обновления, прогноз точки после пропуска — на $h$ шагов от последней точки. Оценка
    аномальности — только в узлах с реальными точками. Оценка параметров по правдоподобию с пропусками.
  - После разрыва по времени больше 180 с прогноз начинается заново: ряд режется на отрезки, каждый
    фильтруется отдельно с параметрами обучающей выборки; первые $p$ точек отрезка — точки без оценки.
  - Ошибка прогноза на $h$ шагов растёт с $h$ (для AR(2) при $\phi=(2,-1)$:
    $\sigma_h=\sigma\sqrt{h(h+1)(2h+1)/6}$, при $h=18$ — около $46\sigma$); нормировка оценки аномальности
    по дисперсии прогноза не применяется (решение о нормировке ниже): точки после пропусков и после серии
    отвергнутых точек получают систематически большую оценку аномальности.
- Член тренда AR — константа (`trend='c'`), как в формуле описания (заменено ниже: уровень — первая точка отрезка);
  `enforce_stationarity=True` (2026-10-30).
  AR на уровне — стационарная модель с притяжением прогноза к точке $\mu$, единичный корень не допускается;
  этим она отличается от ARIMA. При прогоне выводятся $1-\phi_1-\phi_2$ и наибольшее смещение прогноза за шаг
  $(1-\phi_1-\phi_2)\max\lvert\mu-o_j\rvert$ как контроль. Синтетика (размах 675 км, шум 5 м):
  $1-\phi_1-\phi_2\approx7.8\cdot10^{-7}$, смещение до 0.27 м при СКО ошибки прогноза 12 м; $\mu$ оценивается
  неустойчиво и физического смысла не имеет.
  Прогон на `data/test.csv` (2026-10-30): смещение до 39 м за шаг при $\sigma\approx10$ м. Причина: при
  $\phi_1+\phi_2\approx1$ определяется только $c=(1-\phi_1-\phi_2)\mu$, и константа работает как дрейф — средняя
  скорость обучающей выборки ($\mu$ ушло на ~5000 км от трека).
- Уровень AR — первая точка отрезка (2026-10-30, заменяет `trend='c'`): $\mu$ не оценивается, координата
  отсчитывается от первой точки отрезка, `trend='n'`. Отрезок — как для прогноза (после разрыва по времени
  и после перезапуска по серии отвергнутых точек) и как для оценки параметров (между сериями пропусков
  длиннее 180 с). Притяжение — к началу отрезка; контроль: $(1-\phi_1-\phi_2)\max\lvert o_j-\mu\rvert$ по отрезкам и
  точкам штатного хода тестовой выборки между разрывами по времени (прогноз строится от принятых точек).
  Прогон на `data/test.csv`: смещение до 0.09 м за шаг при $\sigma\approx10$ м.
- При оценке параметров на границе области стационарности statsmodels молча возвращает правдоподобие 0;
  целевая функция штрафует такие параметры (проверка корней AR- и MA-многочленов), иначе оптимизатор
  уходит на границу (2026-10-30).
- Доля точек без оценки на тестовой выборке `data/test.csv` — 11–14% у AR и ARIMA, в основном из-за
  перезапусков после 180 с отвергнутых точек; на реальных данных — проверить по столбцам покрытия.
- Порядок AR фиксирован: $p=2$, без подбора по информационному критерию (2026-10-30). По смыслу —
  экстраполяция с постоянной скоростью с параметрами, оценёнными по данным; первые 2 точки каждого отрезка —
  точки без оценки.
- Данные для оценки параметров AR — только точки штатного хода обучающей выборки (2026-10-30). Эталонная
  разметка обучающей выборки используется дважды, на разных шагах:
  1. Оценка параметров (константа, $\phi_1$, $\phi_2$, $\sigma^2$ на ось): аномальные точки обучающей выборки —
     пропуски (`NaN`) на сетке, оценка максимального правдоподобия по точкам штатного хода.
  2. Оценка аномальности на обучающей выборке: фильтр с найденными параметрами проходит всю обучающую
     выборку со всеми точками, как тестовую; аномальные точки не скрываются и входят в лаги. Иначе
     распределение оценки аномальности на обучающей выборке отличалось бы от тестовой и порог сместился бы.
  3. Подбор порога — прежней процедурой: сетка кандидатов из квантилей оценки аномальности обучающей выборки,
     MCC по точкам с оценкой, полоса MCC, наименьшая операционная ошибка длины. Положение порога задают
     аномальные точки обучающей выборки.
  4. Тестовая выборка — те же параметры и тот же порог, без подбора.
  Модель прогноза описывает только штатный ход; классы разделяет порог. В описании модели и в разделе
  отчёта о группах моделей AR переходит из группы «оценка по смеси классов» в группу «обучение на штатном
  ходу». Оценка аномальности точек штатного хода на шаге 2 — внутри выборки; при 4 параметрах на ось
  и ~$10^5$ точках влияние пренебрежимо.
- При оценке параметров AR отрезки режутся по любой серии пропусков длиннее 180 с — разрыву по времени или
  эпизоду аномалии (2026-10-30); параметры общие для всех отрезков, оценка — по сумме логарифмов
  правдоподобия отрезков (`loglike` каждого отрезка, максимизация суммы через `scipy.optimize`).
- Замена отвергнутых точек в лагах (2026-10-30). Если $s_j>\tau_{\mathrm{g}}$, точка размечается как аномалия
  и полностью учитывается в метриках, но в лаги для следующих прогнозов вместо неё идёт прогноз $\hat o_j$:
  на сетке отвергнутая точка — пропуск, следующий прогноз — на $h$ шагов от последней принятой точки.
  - Внутри детектора — экстраполяция (причинная); интерполяция по соседям — только при построении
    заполненной траектории для метрик.
  - Эталонная разметка тестовой выборки в детекторе не используется (только в метриках); замену определяет
    оценка аномальности самой модели.
  - Решение принимается последовательно — свой цикл фильтра AR(2) в numpy вместо одного прохода statsmodels.
  - То же правило (гейтинг) применяется к фильтру Калмана и GP-EKF (пункт 1.3) для единообразия моделей
    прогноза.
  - Порог замены совпадает с порогом решения: $\tau_{\mathrm{g}}=\tau$ (2026-10-30) — отвергнутая точка
    одновременно размечается как аномалия и заменяется в лагах. Для каждого кандидата сетки порогов фильтр
    заново проходит обучающую выборку (оценки зависят от замен); сетка кандидатов — квантили оценки
    аномальности предварительного прогона без замены.
  - Выход из залипания (2026-10-30): после 180 с подряд отвергнутых точек прогноз начинается заново, первые
    2 точки нового отрезка — точки без оценки. Следствие: после перезапуска лаги берутся из текущих точек,
    в том числе аномальных; остаток длинного эпизода аномалии со смещением может быть пропущен.
- Оценка аномальности AR — в метрах, $s_j=\sqrt{r_o^2+r_n^2}$, без нормировки по дисперсии прогноза
  (2026-10-30); квантиль $\chi^2_2$ в сетку кандидатов порога не добавляется.
- ARIMA — общий каркас моделей прогноза с AR (2026-10-30): сетка 10 с с пропусками до 180 с, прогноз заново
  после разрыва больше 180 с, параметры только по штатному ходу с отрезками по сериям пропусков больше 180 с
  и суммой правдоподобий, замена отвергнутых точек в лагах с $\tau_{\mathrm{g}}=\tau$ и перезапуском после
  180 с отвергнутых точек, оценка аномальности в метрах, две независимые модели по осям с общим решением.
  Различие AR и ARIMA — только вид модели: AR(2) — стационарная модель уровня с притяжением к $\mu$;
  ARIMA(2,1,1) — единичный корень, приращения — ARMA(2,1), член скользящего среднего описывает шум GPS.
  - Первые 3 точки каждого отрезка — точки без оценки (одна на приращение, две на лаги AR).
  - Порядок фиксирован: (2,1,1), без подбора по AIC.
  - Член тренда — `'n'` (без дрейфа): средняя скорость по обучающей выборке физического смысла не имеет.
  - `enforce_stationarity=True`, `enforce_invertibility=True`.
  - Реализация (2026-10-30): statsmodels — модель, оценка параметров (`loglike` по отрезкам) и матрицы формы
    пространства состояний (`model.ssm`); последовательная замена отвергнутых точек — свой цикл фильтра numpy
    по этим матрицам, общий для AR и ARIMA. Фильтр statsmodels за один вызов решений по ходу прохода
    не принимает, итеративная замена невыполнима по времени.
- Гейтинг фильтра Калмана и GP-EKF вносится при разборе пункта 1.3, не вместе с AR и ARIMA (2026-10-30).

Фильтр Калмана (постоянная скорость), 2026-10-30:

- Замена отвергнутых точек — по правилам AR: $\tau_{\mathrm{g}}=\tau$, повторный прогон обучающей выборки
  на каждого кандидата сетки порогов, прогноз заново после 180 с подряд отвергнутых точек; оценка
  аномальности — NIS.
- Ограничение шага модели 45 с снимается: переход и шум процесса $Q(\Delta t)$ — по фактическому $\Delta t$.
- После разрыва по времени больше 180 с прогноз начинается заново до оценки точки; первые две точки отрезка —
  точки без оценки. Начальное состояние — по первой паре точек: положение — вторая точка, скорость —
  $(p_2-p_1)/\Delta t$ с ковариацией от шума измерения, а не нулевая скорость (иначе фильтр долго
  «разгоняется»). То же при перезапуске после серии отвергнутых точек. Ковариация начального состояния —
  от шума измерения двух точек: $P=\begin{pmatrix}R&R/\Delta t\\R/\Delta t&2R/\Delta t^2\end{pmatrix}$ (2026-10-30).
- $\sigma_{\mathrm{acc}}$ и $\sigma_{\mathrm{meas}}$ оцениваются по максимуму правдоподобия на точках штатного хода
  обучающей выборки, по отрезкам между сериями пропусков длиннее 180 с, как у AR.
- Совпадающее время — как у AR: остаётся первая точка, остальные — точки без оценки.
- Правдоподобие для оценки $\sigma_{\mathrm{acc}}$ и $\sigma_{\mathrm{meas}}$ — условное: первые две точки отрезка задают
  начальное состояние и в правдоподобие не входят, начиная с третьей точки — прогноз по предыдущим (2026-10-30).
- Сетка порога — общая для всех моделей (см. «Сетка кандидатов порога»); кандидат $\chi^2_{0.999}(2)$ сохраняется.
- Нижние границы оценок (2026-10-30): $\sigma_{\mathrm{acc}}\ge10^{-3}$ м/с², $\sigma_{\mathrm{meas}}\ge0.5$ м — при меньших
  значениях правдоподобие statsmodels численно вырождается в константу и оптимизатор уходит к нулю (на
  `data/test.csv` в сценарии $\rho=0.6$); верхних границ нет, при достижении нижней выводится предупреждение.
- Аномальная точка, принятая после серии отвергнутых (случайно близкая к прогнозу), искажает оценку скорости,
  и следующие точки отвергаются до перезапуска через 180 с; принимается как свойство модели и описывается
  в markdown (2026-10-30).
- GP-EKF разбирается отдельно после фильтра Калмана (2026-10-30); отложен (2026-10-30), варианты A/B/C — в report/notebook_review.md.

GP-EKF, 2026-10-30: вариант A — модель остаётся EKF, форма «усиленного GP» Ko и Fox (GP учит остаток перехода
после модели постоянной скорости):
- правила фильтра Калмана: замена отвергнутых точек с $\tau_{\mathrm{g}}=\tau$, шаг по фактическому $\Delta t$ без
  ограничения 45 с, перезапуск до оценки точки после разрыва по времени и после 180 с отвергнутых точек,
  начальное состояние по первой паре точек, точки без оценки, совпадающее время, оценка аномальности — NIS;
- опорные переходы — по сглаженному состоянию (RTS) на отрезках штатного хода обучающей выборки: вход —
  сглаженная скорость и $\Delta t$, цель — отклонение сглаженного перехода от модели постоянной скорости;
  сглаживатель — только при обучении, фильтр на тестовой выборке причинный;
- гиперпараметры гауссовского процесса (длина корреляции, амплитуда, шум) — по максимуму маргинального
  правдоподобия вместо сетки; опорных переходов 500–1000, выборка случайная.
- Отклонения от статьи: сглаженное состояние вместо истинного (у трека только GPS); вход — скорость и $\Delta t$
  без управления; GP наблюдения не обучается (наблюдение линейно по положению).
- Шум процесса (2026-10-30): $Q_k=\mathrm{diag}(\mathrm{GP}_\sigma)$, как в статье, без $Q_{\mathrm{CV}}(\sigma_{\mathrm{acc}})$
  и без нижних порогов дисперсии `[1, 1, 1e-4, 1e-4]`. Среднее, длина корреляции и амплитуда GP — по маргинальному
  правдоподобию на сглаженных переходах; шум GP $\sigma_n$ (положение, скорость) и $\sigma_{\mathrm{meas}}$ — по
  правдоподобию фильтра на штатном ходу обучающей выборки, как $\sigma$ фильтра Калмана. Причина: сглаживатель
  убирает часть шума процесса, $\sigma_n$ по сглаженным переходам занижает $Q_k$ и NIS на штатном ходу.
  Отклонение от статьи — только способ оценки $\sigma_n$.
- GP учит ускорение-поправку (2026-10-30, уточняет предыдущий пункт): 2 GP, по одному на ось, $a=\mathrm{GP}(v^E,v^N)$;
  переход $\Delta p=v\Delta t+a\Delta t^2/2$, $\Delta v=a\Delta t$; шум процесса — кусочно-постоянное ускорение
  с дисперсией $\mathrm{GP}_\sigma$, масштаб по $\Delta t$ и корреляция положения и скорости, $Q_k$ не диагональна;
  $\sigma_n$ — шум ускорения на ось. Цель обучения — ускорение по сглаженным переходам. Причина: шаг до 180 с,
  у остатков перехода с постоянным $\sigma_n$ шум процесса не растёт с $\Delta t$, опорных переходов с длинным
  шагом почти нет; вход без $\Delta t$ покрыт данными при любом шаге. Отклонение от статьи: GP предсказывает
  ускорение, а не приращение состояния.
- Априорное среднее GP — нуль, без `target_center` (средний остаток — постоянный дрейф, отклонён в ARIMA
  и гауссовском процессе); амплитуда — на выход, по правдоподобию; ручные нижние пороги `target_scale` убираются
  (2026-10-30).
- Вход GP — скорость в ENU $(v^E, v^N)$, выход — ускорение по осям E и N, без положения (2026-10-30). Обучающая
  и тестовая выборки реальных данных — разные районы и маршруты; положение во входе отклонено. Контроль
  при прогоне: доля дисперсии ускорения на штатном ходу, объяснённая средним GP, на обучающей и тестовой выборках.
  Риск: при разных маршрутах курсовые закономерности обучающей выборки могут не переноситься; при заметной доле
  на обучающей и отрицательной на тестовой — рассмотреть продольное и поперечное ускорение со входом $\lvert v\rvert$.
- По аналогии с фильтром Калмана (2026-10-30): первые 2 точки отрезка — точки без оценки; сетка порога — общая

Гауссовский процесс (ячейка «Gaussian process», не GP-EKF), 2026-10-30: постановка заменяется скользящим
причинным гауссовским процессом — для каждой точки прогноз по последним принятым точкам окна $o(t)$, $n(t)$
с дисперсией, оценка аномальности — NIS; гиперпараметры оцениваются по штатному ходу обучающей выборки и
фиксируются. Причина: ядро по абсолютному времени вне ~12 ч от опорных точек сводится к априорному, модель
описывает моменты обучающей выборки, а не динамику. Детали (2026-10-30):
- окно — последние 18 принятых точек текущего отрезка (~180 с); при меньшем числе — имеющиеся, не меньше трёх;
- ядро на оси: $\sigma_{\mathrm{lin}}^2(t-\bar t)(t'-\bar t)+\sigma_{\mathrm{rbf}}^2\exp(-(t-t')^2/2\ell^2)+\sigma_{\mathrm n}^2\delta_{tt'}$,
  $\bar t$ — среднее время окна. Заменено 2026-10-30: оценка $\sigma_{\mathrm{lin}}$ уходит в бесконечность
  (правдоподобие растёт при всё более широком априорном распределении скорости), матрица окна вырождается;
  принят линейный тренд без априорного распределения — универсальный кригинг: $o(t)=\beta_0+\beta_1(t-\bar t)+f(t)$,
  $\beta$ — обобщённым МНК по окну, $f$ — гауссовский процесс с ядром «RBF + шум», неопределённость $\beta$
  входит в дисперсию прогноза;
- оценка аномальности — NIS по двум осям: $\sum(z-\mu)^2/(\sigma^2+\sigma_{\mathrm n}^2)$;
- гиперпараметры $\sigma_{\mathrm{rbf}},\ell,\sigma_{\mathrm n}$ — общие для осей, по максимуму суммы логарифмов
  прогнозной плотности следующей точки на окнах штатного хода обучающей выборки;
- первые три точки отрезка — без оценки; перезапуск, совпадающее время, замена отвергнутых точек — как у AR
  и фильтра Калмана;
- порог — общая сетка (квантили и логарифмическая шкала) плюс кандидат $\chi^2_{0.999}(2)$.
- Свойства модели, принятые как есть (2026-10-30): аномальная точка, принятая в окно, искажает тренд до выхода
  из окна; после паузы короче разрыва по времени (на синтетике 104–160 с) прогноз продолжает тренд окна без

  отклонены — приближают модель к фильтру Калмана.

DBSCAN, 2026-10-30: постановка A — DBSCAN обучается на точках штатного хода обучающей выборки, результат — набор
опорных (core) точек; точка любой выборки — аномалия, если расстояние в пространстве признаков до ближайшей опорной
точки больше ε (правило отнесения к кластеру DBSCAN). Тестовая выборка заново не кластеризуется; решение по точке
не зависит от остальных точек выборки. ε — по разметке обучающей выборки. Причина: перекластеризация теста
делает разметку зависящей от состава теста (п. 1.4); кластеризация всей обучающей выборки при 61–70% аномалий
превращает длинные эпизоды в кластеры.
- Признаки (2026-10-30): $(v_i,\ a^{\mathrm{long}}_i,\ a^{\mathrm{lat}}_i)$ — скорость, продольное ускорение $(v_i-v_{i-1})/\Delta t_i$,
  поперечное ускорение $v_i\,\Delta\psi_i/\Delta t_i$; по последней принятой точке (второй проход); робастная
  нормировка по штатному ходу обучающей выборки; первые 2 точки отрезка — без оценки. Причина: признаки
  не зависят от курса (маршруты выборок разные) и от $\Delta t$; поперечное ускорение мало на стоянке, где курс
  случаен; индекс формы удлиняет начало отрезка без оценки до 6 точек и повторяет MPCT.
- ε и MinPts (2026-10-30): MinPts = 6 ($2d$ при $d=3$) без подбора; ε — 30 квантилей расстояния до 6-го соседа
  на штатном ходу обучающей выборки (уровни 0.5–0.999); выбор — как порог (максимум MCC, полоса, операционная
  ошибка длины); своя сетка вместо общей — на каждое ε ядровые точки находятся заново.
  Границы уровней: $q$ — доля ядровых точек штатного хода; при $q<0.5$ норма сжимается до плотного ядра и
  отвергается заметная часть штатного хода; $q=1$ — кандидат задаёт самая изолированная точка штатного хода
  (ошибка разметки); границы выбраны без подбора (прежняя сетка 0.5–0.97); на test.csv выбрано $q\approx0.96$.
- По аналогии с AR и фильтром Калмана (2026-10-30): признаки для обучения (нормировка и ядровые точки) — по соседним
  точкам штатного хода, аномальные точки пропускаются, отрезки — между сериями пропусков длиннее 180 с; разметка —
  в два прохода на каждое ε. Ядровые точки (core points) — термин DBSCAN; «опорные точки» заняты GP-EKF.

LOF, 2026-10-30: постановка A — LOF в режиме обнаружения новизны (novelty): обучение на точках штатного хода
обучающей выборки, оценка любой точки относительно её соседей среди них; тестовая выборка не пересчитывается.
Признаки, нормировка, точки без оценки и второй проход — как у DBSCAN (сравнение методов при одинаковых
признаках); порог — общая сетка. Причина: LOF — относительная величина, при пересчёте на тесте шкала зависит
от состава теста (п. 1.4); обучение на всей обучающей выборке делает длинные эпизоды «нормой». Отличие от DBSCAN —
непрерывная оценка относительной локальной плотности против бинарного правила с глобальным ε.
- Число соседей $k$ (2026-10-30): подбирается вместе с порогом по сетке $k\in\{10, 20, 35, 50\}$ × общая сетка порога
  (для каждого $k$ — своя сетка по оценке первого прохода, второй проход на каждого кандидата); выбор по всем парам —
  максимум MCC, полоса, операционная ошибка длины. Точки штатного хода обучающей выборки, входящие в набор обучения,
  оцениваются без самой точки среди соседей (стандартный LOF обучающей выборки); кандидаты 1.5 и 2.0 убираются.
- Свойства модели (2026-10-30), описываются в markdown и отчёте: (1) риск принят — совпадающие признаки (стоянка
  с повторяющимися координатами) дают огромную $\mathrm{lrd}_k$, у соседних точек LOF ~10⁹, ложные срабатывания
  у стоянок; на test.csv совпадающих признаков нет, на реальных данных не проверено; (2) оценка штатного хода слабо
  зависит от $k$ (на test.csv медиана 1.02–1.03, p99 1.46–1.60 при k 10–50) — выбор $k$ определяется малыми
  различиями MCC и может меняться между сценариями (на test.csv 10 и 35).

Isolation Forest, 2026-10-30: постановка A — лес обучается на точках штатного хода обучающей выборки (обнаружение
новизны) и применяется к любой выборке без переобучения; признаки, нормировка, точки без оценки и второй проход —
как у DBSCAN и LOF; оценка аномальности $s_i=2^{-\bar h/c(n_{\mathrm{sub}})}$; порог — общая сетка плюс канонический кандидат 0.5;
200 деревьев, подвыборка $n_{\mathrm{sub}}=256$, фиксированный seed — без подбора. Причина: при 61–70% аномалий в обучающей
выборке длинные эпизоды для леса без учителя не редки и не изолируются; аномалии используются для выбора порога.

One-Class SVM, 2026-10-30: постановка A — признаки, нормировка, точки без оценки и второй проход — как у DBSCAN,
LOF, Isolation Forest; обучение на всех точках штатного хода обучающей выборки (без подвыборки 4000: при трёх
признаках обучение ~$n^2$, на $3.2\cdot10^4$ точек — 5 с, на $10^5$ — порядка минуты); оценка $s_i=-f(\mathbf u_i)$
непрерывна, порог — общая сетка плюс канонический 0 (граница SVM); ν = 0.1 фиксирован (решение 2026-10-30: оценка
ближе к сглаженной оценке плотности и информативна во всём пространстве признаков; опорных векторов ≥ 0.1·n);
γ = 1/(d·Var(T)) (gamma = 'scale' sklearn) без подбора. Причина:
одна подбираемая величина (порог), как у большинства моделей; 3 значения ν были грубой сеткой (п. 3.1).
- Свойство модели (2026-10-30): далеко от области штатного хода оценка насыщается на ρ, далёкие точки не различаются;
  на решение не влияет при пороге ниже ρ; описано в markdown и отчёте.

Robust PCA, 2026-10-30: постановка A — подпространство «типичного поведения» $L$ и нормировка — по окнам штатного
хода обучающей выборки; окно любой выборки раскладывается на проекцию на фиксированное подпространство и
разреженный остаток $\mathbf s$; оценка точки — величина $\mathbf s$ на её позициях; разложение на тестовой выборке
не повторяется; признаки $(v, a^{\mathrm{long}}, a^{\mathrm{lat}})$; точки вне окон — без оценки; общая сетка порога.
Причина: переразложение теста делает $L$ и шкалу $S$ зависящими от состава выборки (п. 1.4); при 61–70% аномалий
длинные эпизоды уходят в $L$. Отличие от точечных моделей — согласованность точки с соседями в окне; $\ell_1$
локализует отклонение в точке, обычный остаток проекции размазывает его по окну.
- Детали (2026-10-30): (1) подпространство — разложение $X=L+S$ (PCP, λ = 1/√max(n, m)) на окнах штатного хода
  обучающей выборки, базис — правые сингулярные векторы $L$, ранг — по разложению; итерации до сходимости с проверкой;
  (2) окно любой выборки — $\mathbf c^*=\arg\min\lVert\mathbf x-U\mathbf c\rVert_1$, остаток $\mathbf s=\mathbf x-U\mathbf c^*$ (без
  параметров, PCP при известном подпространстве); (3) окна 16 точек внутри отрезка, шаг 1, оценка точки — максимум
  по покрывающим окнам; без оценки — первые 2 точки отрезка и отрезки короче 18 точек; длина окна без подбора;
  (4) второй проход, как у остальных моделей.
- Расчёт остатка окна (2026-10-30): точно, линейным программированием (HiGHS) по каждому окну; IRLS отклонён —
  решение ℓ1 часто неединственно, коэффициенты «плывут», остановка не срабатывает (на test.csv 150 с на 3373 окна,
  ℓ1 в пределах 1e−4 от точного); ADMM не сошёлся. Цена: ~15 мс на окно, ~25 мин на полный проход по 1e5 окон
  (оценка); остатки первого прохода считаются один раз на выборку, во втором — только изменённые окна.

LSTM-автоэнкодер, 2026-10-30: постановка A — обнаружение новизны (обучение на окнах штатного хода обучающей
выборки); вход — признаки $(v,a^{\mathrm{long}},a^{\mathrm{lat}})$ с нормировкой как у DBSCAN; окна 16 точек внутри
отрезка (разрыв 180 с), шаг 1, как у Robust PCA; калибровка на непересекающемся по времени блоке штатного хода;
оценка точки — по ошибке реконструкции её собственных признаков; точки без оценки, второй проход, общая сетка
порога. Причина: относительные координаты зависят от курса (маршруты разные) и Δt; случайная калибровка при шаге
окон 1 занижает ошибку; максимум оценки окна делает аномальными все точки окон с выбросом. Отличие от Robust PCA —
нелинейная модель последовательности.
- Детали (2026-10-30): (1) оценка точки — минимум по покрывающим окнам ошибки её собственных признаков,
  нормированной по калибровке для позиции в окне: выброс плох во всех своих окнах, у соседа есть окно без выброса;
  максимум переносит ошибку выброса на соседей, медиана испорчена при выбросе вплотную; (2) калибровка — последние 15%
  окон штатного хода по времени, пересекающиеся с обучающими окна отбрасываются; (3) скрытое состояние 32, до 50 эпох
  с ранней остановкой (5 эпох без улучшения на калибровке), до 8000 окон обучения, фиксированный seed torch
  и детерминированный режим, без подбора; (4) обрезка ±30 км убирается.
- Обучение нейросетей LSTM, TCN, DONUT (2026-10-30, уточняет п. 3): до 300 эпох вместо 50 — на проверках обучение
  упиралось в лимит 50; терпение 10 эпох; эпоха лучше, если ошибка на калибровке упала больше чем на 1e−4
  (относительно); ReduceLROnPlateau — скорость обучения вдвое после 3 эпох без улучшения; предупреждение при остановке
  по лимиту. Общая функция train_with_early_stopping и константы NN_* — в общих ячейках; N_EPOCHS удалена.

TCN, 2026-10-30: постановка A — причинный одношаговый прогноз признаков: по признакам $(v,a^{\mathrm{long}},a^{\mathrm{lat}})$
предыдущих принятых точек сеть предсказывает признаки следующей точки (Δt входит в её признаки); оценка —
нормированный остаток прогноза; обучение на штатном ходу, калибровка на блоке по времени, ранняя остановка,
фиксированный seed — как у LSTM; второй проход; общая сетка порога. Причина: относительные координаты зависят
от курса, сеть не знала шага по времени до прогнозируемой точки; выброс в истории портил 16 следующих прогнозов.
Отличие от LSTM — причинный прогноз вместо восстановления окна; от AR и фильтра Калмана — нелинейная модель
по признакам.
- Детали (2026-10-30): (1) история 15 точек — поле зрения сети (3 уровня, ядро 3, расширения 1, 2, 4), 32 канала;
  (2) оценка — диагональный Махаланобис остатка прогноза трёх признаков по калибровке; (3) без оценки — первые 17
  точек отрезка (2 на признаки, 15 на историю), дубликаты времени; (4) калибровка, до 8000 окон, до 50 эпох
  с ранней остановкой, seed — как у LSTM, обрезка ±30 км убирается; (5) второй проход — история из принятых точек.

DONUT, 2026-10-30: постановка A — DONUT по статье с общими правилами: признаки $(v,a^{\mathrm{long}},a^{\mathrm{lat}})$;
окно — 15 предыдущих принятых точек и точка $i$ (причинно, оценивается последняя точка, как в статье); VAE
с априорным $\mathcal N(0,I)$ и обучаемой дисперсией наблюдения; обучение на всех окнах обучающей выборки с M-ELBO —
правдоподобие аномальных точек исключается (разметка используется при обучении, как в статье); оценка точки —
минус вероятность реконструкции её признаков; ранняя остановка и seed — как у LSTM; первые 17 точек отрезка — без
оценки; второй проход; общая сетка порога. Причина: в текущем коде априорное распределение $z$ — сам энкодер
(KL = 0, план 1.2), от DONUT остались только окна и VAE.
- Детали (2026-10-30): (1) кодировщик и декодер — по два слоя из 100 нейронов, $z$ размерности 8, декодер выдаёт
  среднее и СКО признаков (СКО ≥ 1e−4); (2) M-ELBO: $\alpha_j=1$ у штатного хода, 0 у аномалии, KL с множителем
  $\beta$ — долей штатных точек окна, 1% точек при обучении случайно получает $\alpha_j=0$, окна из одних аномальных
  точек исключаются; признаки при обучении — по последней точке штатного хода (иначе след аномалии у соседней
  точки попал бы в норму); (3) оценка — минус средний логарифм вероятности признаков последней точки по $L=100$
  выборкам $z$, seed фиксирован; (4) восстановление пропусков при оценке не делается — во втором проходе в окне
  только принятые точки; (5) обучение и калибровочный блок — как у LSTM; (6) первые 17 точек отрезка — без оценки,
  второй проход, общая сетка порога.

HMM, 2026-10-30: постановка A — одна HMM с переключением: состояния штатного хода ($K_N$) и аномалии ($K_A$) в одной
цепи; эмиссии и переходы (в том числе между классами) — EM на всех отрезках обучающей выборки, в размеченной точке
допустимы только состояния её класса; оценка — причинная апостериорная вероятность аномалии $P(S_i\in A\mid o_{1:i})$;

общая сетка порога плюс 0.5. Причина: три независимые модели не моделируют переходы между классами — устойчивость
длинных эпизодов, главное, что даёт HMM; обучение на 6 отрезках класса — произвольная подвыборка; модель «быстрых»
аномалий (8 м/с) — ручная подстройка.
- Детали (2026-10-30): (1) $K_N=K_A=3$ без подбора; (2) EM до сходимости (относительный прирост логарифма
  правдоподобия < 1e−4, ≤ 200 итераций), 5 запусков с фиксированными seed, лучший по правдоподобию, предупреждение при
  несходимости; (3) разметка — нулевая вероятность состояний чужого класса в размеченной точке, ограничение
  добавляется к hmmlearn; (4) начальное распределение — по первым точкам отрезков, перезапуск фильтра в начале
  отрезка, первые 2 точки без оценки; (5) оценка $P(S_i\in A\mid o_{1:i})$, канонический кандидат 0.5 плюс общая
  сетка; (6) второй проход; признаки при обучении — по последней точке штатного хода (как у DONUT).
- Свойство модели (2026-10-30): после одиночного выброса цепь остаётся в режимах аномалии и размечает аномалией ещё
  несколько точек (на синтетике ~7; с эпизодами 5–60 точек — TP 779, FP 134) — следствие выученной длительности

MPCT, 2026-10-30: постановка A — по статье: в каждом отрезке между разрывами по времени — самая длинная
подпоследовательность точек со скоростью между соседними выбранными точками не выше $v_+$ (динамическое
программирование, предшественник — среди точек за последние 180 с); аномалии — точки вне неё; без индекса формы;
$v_+$ — единственный параметр, частая сетка по MCC; пакетная модель. Причина: жадный якорь попадает в ловушку
(аномальный якорь отвергает штатные точки), нет перезапуска после паузы, индекс формы оставляет след выброса и даёт
ложные срабатывания на стоянке, его нет в статье.
- Детали (2026-10-30): (1) расстояние — евклидово в плоскости ENU, как у всех моделей (все модели измеряют одно
  и то же; геодезическое отклонено); (2) цепочка начинается заново, если от последней выбранной точки прошло больше
  180 с (как перезапуск у остальных моделей); свойство: смещённый физически согласованный эпизод длиннее 180 с может
  оказаться выбран вместо штатных точек, если он длиннее; (3) сетка $v_+$ — 30 значений, равномерных в логарифмической
  шкале от 95-го процентиля скоростей между соседними точками штатного хода обучающей выборки до трёх их максимумов;
  выбор как порог; (4) решение бинарное, непрерывной оценки нет — роль порога играет $v_+$; (5) из точек с одинаковым
  временем — первая, остальные без оценки; второй проход не нужен; (6) при равной длине — ближайший по времени
  предшественник.

перцентилем и максимумом (при неположительном 1-м перцентиле — равномерных). Причина: распределение оценки
двугорбое (штатный ход — метры, аномалии — тысячи метров), квантили не дают кандидатов в провале. Пример
на синтетике с дрейфом и аномалиями: у AR выбирался порог 1216 м (MCC 0.764) при MCC 0.997 у порога 200 м;
после исправления — 92.9 м, TP 166, FP 0, FN 1. Модели с собственной дискретной сеткой гиперпараметров
(MPCT, DBSCAN, One-Class SVM) не затрагиваются. Описания порога в markdown остальных моделей («по квантилям»)
синхронизируются при их разборе.

### 1. Ошибки реализации, меняющие результаты

- [x] AR и ARIMA (строки ~1829, ~2063): `get_prediction(start=0, dynamic=True)` — прогноз без обратной связи
      на весь ряд, а не причинный одношаговый прогноз, как в markdown, отчёте и `methods.md`. На синтетике
      медианная ошибка ~21 м против ~2 м при `dynamic=False`. Объясняет разметку «всё аномалия» в сценарии
      $\rho=0.8$, совпадение AR и ARIMA и задержку обнаружения в часы; объяснение в отчёте (смесь классов

      описания AR(2) и ARIMA(2,1,1) в отчёте обновлены по markdown-ячейкам (2026-10-30); осталось: прогон на реальных
      данных, затем выводы блокнота, таблицы и разбор в отчёте, `docs/notes/methods.md` (после подтверждения).
- [ ] DONUT (строка ~5356): в генеративной модели Pyro априорное распределение `z` взято из энкодера
      (совпадает с гайдом) → KL-член ELBO равен нулю, обучается автоэнкодер без регуляризации;
      член $\mathrm{KL}(q\|\mathcal N(0,I))$ в оценке аномальности не обучался и произволен. Априорное
      распределение — $\mathcal N(0,I)$.
- [x] Фильтр Калмана и GP-EKF (строки ~2307, ~2992): нет гейтинга — точка с большим NIS обновляет

      Фильтр Калмана: код, markdown и описание в отчёте — 2026-10-30; GP-EKF — 2026-10-30 (код, markdown, отчёт).
- [ ] Перенос порога на шкалу тестовой выборки: Robust PCA (строка ~4516) — `robust_params` по матрице окон

      (обнаружение новизны по штатному ходу); Robust PCA — при разборе.

### 2. Метрики и их интерпретация

- [ ] Агрегаты задержки обнаружения только по эпизодам с $\mathrm{Delay}_k>0$ (`temporal_metrics.py`):

      «всё аномалия» даёт только своевременные обнаружения (AR и ARIMA в сценарии $\rho=0.8$). Считать
      агрегаты по всем эпизодам аномалии, выводить число эпизодов.
- [ ] RMSE только по $d_i>0$ (`geospatial_metrics.py`): знаменатель свой у каждой модели, RMSE между
